# SAIRA — فروشگاه اینترنتی اکسسوری زنانه

فروشگاه اینترنتی فارسی و RTL برای برند SAIRA، ساخته‌شده با Next.js 14، TypeScript، Tailwind CSS و Supabase.

## شروع سریع

راهنمای کامل راه‌اندازی (ساخت Supabase، اجرای Schema، تنظیم Environment Variables، اجرا و Deploy) را در فایل [`ADMIN_SETUP.md`](./ADMIN_SETUP.md) بخوانید — این راهنما برای افراد غیر Developer نوشته شده است.

خلاصه برای Developerها:

```bash
cp .env.example .env.local   # و مقادیر Supabase را پر کنید
npm install
npm run dev
```

سپس Schema و Seed را از `supabase/schema.sql` و `supabase/seed.sql` در SQL Editor پروژه Supabase اجرا کنید.

## ساختار پروژه

```
app/                    صفحات (App Router)
  admin/                پنل مدیریت (محافظت‌شده با middleware)
  api/                  Route Handlers (سفارش، جستجو، عملیات ادمین)
  shop, product, cart, checkout, ...   صفحات فروشگاه
components/             کامپوننت‌های reusable
lib/                    کلاینت‌های Supabase، types، توابع کمکی، cart/wishlist context
supabase/               schema.sql و seed.sql
public/placeholders/    تصاویر Placeholder دسته‌بندی‌ها (تا زمان آپلود عکس واقعی)
```

## ویژگی‌های کلیدی

- کاملاً فارسی و RTL
- محصولات، دسته‌بندی‌ها، سفارش‌ها و محتوای صفحه اصلی همگی از Supabase خوانده می‌شوند (چیزی Hard-coded نیست)
- پنل مدیریت با احراز هویت Supabase Auth + لیست ایمیل مجاز (`ADMIN_ALLOWED_EMAILS`)
- **حساب کاربری مشتری**: ورود/عضویت با شماره تلفن و کد تایید پیامکی (بدون ایمیل/رمز عبور)، ویرایش پروفایل، و پیگیری وضعیت سفارش‌ها از `/account`
- مدیریت کامل محصولات، دسته‌بندی‌ها، سفارش‌ها، تنظیمات و محتوای صفحه اصلی بدون نیاز به کدنویسی
- سبد خرید و علاقه‌مندی‌ها (Local، مستقل از حساب کاربری)
- آماده برای اتصال درگاه پرداخت ایرانی (فعلاً بدون پرداخت آنلاین واقعی)

## محدودیت‌های شناخته‌شده (صادقانه)

- **پرداخت آنلاین واقعی وجود ندارد.** سفارش‌ها ثبت می‌شوند اما تراکنش مالی واقعی انجام نمی‌شود.
- سفارش‌های مهمان (بدون ورود) به هیچ حسابی متصل نیستند و در «سفارش‌های من» نمایش داده نمی‌شوند.
- تصاویر محصولات، Placeholder برداری (SVG) هستند تا زمانی که عکس واقعی از پنل مدیریت آپلود شود.
- این پروژه در یک محیط sandbox بدون دسترسی به npm registry یا Supabase واقعی نوشته شده، بنابراین `npm install` و اتصال دیتابیس هنوز تست نشده‌اند — لطفاً طبق `ADMIN_SETUP.md` محلی اجرا و تست کنید.
